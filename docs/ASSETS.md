# 教学资产约定与记录

用户已授权助手按课程需要从开源/免费来源获取模型、纹理、HDRI、动画和音频。助手负责检索、下载、校验、整理和必要的文件准备；用户负责引擎中的解析、加载、渲染和其他课程实现。

当前为 L00 工程课程，尚不需要外部资产，已下载清单为空。

## 获取方式

1. 先明确课程用途和当前加载器支持的格式，再选择最小测试资产。先用简单、容易核对结果的内容，随后加入复杂场景。
2. 检查该资产的具体许可和作者说明，优先 CC0 或明确允许项目所需使用、修改及分发的内容。仅“免费下载”不足以决定后续使用方式。
3. 获取实际用到的文件和它们的依赖，如 glTF 引用的 `.bin`、纹理；优先小分辨率和小数据量版本。
4. 记录原始页面、下载地址、版本/提交或获取日期、SHA-256、作者和许可。保存许可文本及必要署名。
5. 如有重命名、裁剪或格式转换，保留原始来源并记录修改。外部文件准备不代替用户要学习的导入器和资源管线代码。

## 下载后的登记字段

第一项资产获取时在此新增记录，包括：内部名称、课程用途、本地相对路径、来源页面、具体下载地址、作者、许可与署名文件、版本/提交或获取日期、SHA-256、大小、格式及修改情况。

原始下载资产放在 `assets/` 的相应用途目录，许可信息随资产保存。缓存和可重新生成的烘焙产物与原始资产分开；具体布局在资源课程中确定。助手不会为了预备课程提前批量下载整个大仓库。
